# Personal Portfolio

This is my portfolio project.

navbar/header
Create a responsive website header with a fixed top bar containing:
- A logo on the left (text-based, e.g. "Code Ninja")
- A hamburger icon (☰) on the right that is hidden on desktop and shown on mobile
- A navigation menu with links to Home, About, Projects, Skills, and Contact (anchor links: #home, #about, #projects, #skills, #contact)
- On mobile, clicking the hamburger toggles a grid-style dropdown/overlay menu (class "mobile-menu") via a toggleMenu() JavaScript function
- Style: clean, modern, sticky/fixed positioning, using Poppins/Roboto Google Fonts


hero section
Create a hero section for a developer portfolio with:
- A two-column layout: text content on one side, an illustration image on the other
- Heading with the developer's full name
- Subheading stating their role (e.g. "Full-Stack Developer")
- A "Download Resume" button that links to and downloads a PDF file from a /cv folder
- An illustration/avatar image on the opposite side
- Responsive: stacks vertically on smaller screens
