About Me

I’m a Full-Stack Developer focused on building scalable, secure, and user-centered web applications. I work across both frontend and backend development, with hands-on experience designing REST APIs, authentication systems, real-time features, database architectures, caching strategies, background processing, and responsive user interfaces.

My core technologies include JavaScript, TypeScript, React, Next.js, Node.js, NestJS, MongoDB, and Redis. I also work with technologies such as TanStack Query, Socket.IO, BullMQ, JWT, Cloudinary, Cloudflare, and modern web security practices.

One of my main projects is SocialMarketHQ, a social-commerce platform combining social networking, marketplace features, shops, messaging, product listings, location-based discovery, stories, requests, and real-time interactions.

Building SocialMarketHQ has given me practical experience with scalable architecture, API design, caching, queue-based processing, media optimization, database indexing, pagination, security, performance optimization, and reducing unnecessary database queries.

I enjoy solving real-world engineering problems and turning complex ideas into reliable, maintainable digital products. I’m particularly interested in building systems that can scale to large numbers of users while remaining fast, secure, and cost-efficient.

I’m continuously improving my engineering skills through hands-on development, system design, debugging, testing, and learning how production applications are built, secured, optimized, and maintained.
